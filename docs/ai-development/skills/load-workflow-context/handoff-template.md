# Issueの引き継ぎファイル（記入用）

Issueごとにこのひな形をコピーし、人間が承認した記録先に置きます。Issue作成前から使う場合は、Issue URLを「未作成」にしておき、作成後に記入します。空欄は未確認として扱い、不要な項目は「該当なし」と記載します。変更があった項目だけを更新し、承認記録は参照先を記載します。

| 項目 | 値 |
| --- | --- |
| Issue URL | |
| PR URL | |
| 採用資料SHA | |
| 設計資料・採用版（軽微案件はIssue内の簡易設計の参照先） | |
| 設計承認記録の参照先・承認者 | |
| リスク区分・追加ゲートの確認記録 | |
| 設計資料の未公開状態・変更／提出可否の確認記録 | |
| 専任AI担当（未起動／継続担当IDと再開記録） | |
| 作業場所・人間が用意した専用worktree（同じ端末で照合に必要な場合のみ） | |
| 作業ブランチ（Gitの取得値に対して期待するブランチを指定する場合のみ） | |
| 業務上の確認窓口・技術設計の承認者（社内で共有可能な参照先） | |
| 中断時の記録（成功済み・失敗／結果不明・未完了・再開先の参照先） | |

リポジトリ、マージ先の扱い、CI・レビュー条件は案件別設定を参照し、ここに転記しません。端末固有の絶対パスはローカル記録に限り、別端末では同じ値を使い回しません。認証情報や顧客の機密情報、個人情報は記載しません。このファイルを工程の実行依頼や承認そのものとして使わないでください。
